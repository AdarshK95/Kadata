Help: these pages and the live server

What these pages are. A view of this project's A Skill files (the board, each feature's file, decisions, lessons), rebuilt from them. Nothing here is edited by hand; the files stay the source.

Open them live: type /A.show in a chat about this project. It builds the pages, starts the live server and opens this page at http://localhost:8718/index.html (the same address every time for this project).

Or from a terminal:

  • Start the live server: python "C:\Users\User\.a\templates\pages\page_build.py" --root "C:\Writer - Kannada" --serve
  • Stop it: python "C:\Users\User\.a\templates\pages\page_build.py" --root "C:\Writer - Kannada" --stop
  • Build the pages once, no server: python "C:\Users\User\.a\templates\pages\page_build.py" --root "C:\Writer - Kannada"
  • Windows, start it at every login: python "C:\Users\User\.a\templates\pages\page_build.py" --root "C:\Writer - Kannada" --install-startup (undo: python "C:\Users\User\.a\templates\pages\page_build.py" --root "C:\Writer - Kannada" --remove-startup)

When it starts by itself: the setting pages_server in ~/.a/settings.md (or in this project's .a/project.md, which wins): off only on /A.show; session also while the agent works (the default); login also at Windows login.

Without the server (this page opened as a file) the page reloads every 15 seconds and Resync is off. A web page cannot start a program on your computer, so the server is always started by /A.show or the command above.
